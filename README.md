# Currency Converter Application

## Описание проекта

Приложение для конвертации валют с функцией расчета кредитных платежей. Позволяет:
- Рассчитать ежемесячный платеж по кредиту
- Конвертировать сумму платежа в различные валюты
- Получать актуальные курсы валют через API

## Технологии

- **Python 3.10+**
- **Tkinter** - GUI фреймворк
- **SQLite** - база данных для хранения курсов валют
- **Requests** - HTTP библиотека для работы с API
- **pytest** - фреймворк для тестирования
- **Black** - линтер для форматирования кода
